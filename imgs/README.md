💍 NeXoRa Weddings - Premium Mediator Portal
NeXoRa is a high-end wedding planning and mediation platform designed to bridge the gap between luxury vendors and couples. Built with a focus on Glassmorphic UI, responsive performance, and seamless user transitions, NeXoRa provides a "Single-Source-of-Truth" for event planning.

🌟 Key Features
Glassmorphic Navigation: A high-blur, translucent navigation system with "Gold & Maroon" brand accents.

Dynamic Event Filtering: A JavaScript-powered category engine for instant sorting of blog stories and vendors.

Responsive Side-Nav: A mobile-optimized menu using Tailwind's viewport-specific utility classes.

Interactive Consultation Portal: A validation-ready contact system with dynamic success modals.

Performance Optimized: Utilizing IntersectionObserver for scroll-reveal animations and requestAnimationFrame for buttery-smooth UI updates.

🛠️ The Tech Stack
Language: HTML5, JavaScript (ES6+)

Styling: Tailwind CSS (Utility-first framework)

Icons: FontAwesome 7.0

Typography: Playfair Display (Headings) & Poppins (Body)

Version Control: GitHub (Collaborative Team Workflow)
